Anmelden

Einmalig einrichten: Auf github.com/settings/personal-access-tokens/new einen Fine-grained Token erstellen — Repository access: nur dieses eine Repo (turmhotel), Permissions: Contents → Read and write (sonst nichts). Der Token wird nur in diesem Browser-Tab gespeichert (verschwindet beim Schließen) und geht an niemanden außer GitHub selbst.
